# 📝 Blog Post Card (freeCodeCamp Lab)

Una tarjeta de publicación de blog interactiva desarrollada con **HTML5** y **CSS3**. Este proyecto forma parte de los laboratorios prácticos de la certificación de diseño web adaptable de **freeCodeCamp**, enfocado en el manejo avanzado de fondos, bordes y efectos interactivos.

---

## 🚀 Características del Proyecto

* **Diseño de Tarjeta Responsiva:** Contenedor centralizado con bordes redondeados, sombras suaves y ancho definido.
* **Imagen de Portada Adaptable:** Imagen integrada con un borde inferior distintivo y ajuste automático al ancho de la tarjeta.
* **Tipografía y Estilos Personalizados:** Títulos y extractos con colores y márgenes estilizados para una mejor legibilidad.
* **Botón Interactivo (`Read More`):** Enlace con diseño de botón, esquinas redondeadas, relleno y efecto hover dinámico para la transición de color.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5** (Estructura semántica, imágenes con atributos `alt`, contenedores y enlaces)
* **CSS3** (Estilos visuales, selectores, propiedades de caja, pseudoclases y transiciones)
